# @aperture-engine/render

## 0.3.0

### Minor Changes

- Add typed-array-safe `RenderSnapshot` JSON codecs and source asset registry mirroring support for saved render bundles.

- Move particle contracts to `@aperture-engine/particles` behind compatibility exports and add Shuriken-style particle module support for stateful continuous particles, texture sheets, rate-over-distance, bursts, velocity, force, size, color, and billboard rotation.

- Resolve render-side issues #59-#76, including render bundle closure/tonemap metadata and importer-ready diagnostics.

### Patch Changes

- Updated dependencies:
  - @aperture-engine/particles@0.3.0
  - @aperture-engine/simulation@0.3.0
