# Crane wall continuity evidence

Read [ANALYSIS.md](ANALYSIS.md) for findings, limits and the seven capture links. This is an immutable diagnostic extension using existing extrusion APIs; it does not change engine sources or the earlier comparison/diagnostic archives.

`cases.json` defines exact comparators and source pins. `geometry-guards.py` contains the independent coverage/equivalence checks, and every capture has a retained native guard result. Cloned author files are provenance inputs; the extension's independent guards handle the continuous indexed body and replace assumptions in legacy author-specific validators about the original 16 named brick parts.

The native attempt budget is exhausted. Rerunning work requires a new separately bounded archive, not edits to these cases or evidence.
