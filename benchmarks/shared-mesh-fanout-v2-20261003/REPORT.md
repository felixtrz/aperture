# V2 preparation report

## Finding

The V1 observer could not prove indirect arguments. The engine's installed
indirect conversion selects coalesced commands with at least two instances,
allocates INDIRECT|COPY_DST, uploads 20-byte slots, and emits native indirect
buffer/offset calls. A nonindexed slot consumes its first 16 bytes. Indexed
arguments use 20 bytes, including signed baseVertex. The source/compiled route
and preserved V1 queued-standard-material diagnostics are pinned in SOURCE_TRACE.

The V1 failure is retained in its original folder, including partial bytes,
failure/outcome diagnostics and lifecycle completion. No attempt is accepted,
retroactively repaired or inferred to have drawn three instances. V2 must obtain
new native evidence under separate admission.

The observer records genuine methods and actual argument-buffer object IDs.

so insufficient evidence produces an evidence error rather than a batching
diagnosis. All geometry, transform, command, version, shadow and equality checks
still run. Indexed formats are decoded and CPU-tested; this fixture's actual
nonindexed geometry still rejects indexed draws.

Unobserved encoded buffer mutations invalidate ranges on submission, including
operations in other command buffers of the same queue.submit. This conservative
rule can reject a draw that precedes a later mutation. It never guesses GPU
results. STORAGE and QUERY_RESOLVE argument usages remain unsupported even if a
CPU upload was observed. Argument bytes must be fully initialized and come from
the same object and submission, with no overlapping uncertainty. Validated
arguments remain upload observations, not GPU readback.
