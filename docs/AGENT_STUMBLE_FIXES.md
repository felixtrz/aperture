# Agent Stumble Fixes

Source: a forensic audit of 23 AI-agent chat histories (Codex + Claude Code)
that built the downstream **Prism** app on Aperture
(`prism/agent-stumble-report.md`, 2026-07-07). The audit surfaced 35 distinct
stumbles. This document maps each to its Aperture-side resolution — or records
why it is out of Aperture's scope — so the fix set is reviewable against the
report.

Principles held: deterministic simulation-first iteration, typed assets and
results, structured diagnostics, machine-checkable state over pixels. None of
the fixes change simulation semantics; they harden boundaries, close a
transport race, and add sanctioned, deterministic query surfaces that agents
previously hand-rolled.

## Adversarial review round (Codex CLI)

An independent Codex CLI review of this change set surfaced five findings,
all fixed and regression-tested:

1. **Registry epoch reset** — a worker restart starts a fresh interning
   registry; keeping the "newest by entry count" snapshot could silently
   decode new frames against the stale registry (wrong assets, no error).
   The decoder now prefix-validates snapshots and resets its cache when the
   incoming registry is not an append-only extension of the cached one.
2. **Typed registry-miss error** — the transient-lag skip previously caught
   every `RangeError`, which would also have swallowed truncated-buffer /
   bad-magic corruption. Registry misses are now a typed
   `SnapshotPacketRegistryMissError`; all other decode failures surface.
3. **Pick honors the rendered rectangle** — `viewport_pick` now clamps the
   viewport and intersects the scissor exactly as the renderer does, and
   reports `aperture.headless.pickOutsideView` for pixels the renderer never
   shades instead of returning bounds hits for clipped-away points.
4. **Headed `untilQuiescent` fails loudly** — the headed devtools bridge has
   no quiescence loop, so `ecs_step { target: "headed", untilQuiescent }`
   returns `aperture.mcp.untilQuiescentHeadlessOnly` instead of silently
   stepping a single frame.
5. **Stale render help text** — `aperture render` usage/error text no longer
   describes the pre-headless-default behavior.
